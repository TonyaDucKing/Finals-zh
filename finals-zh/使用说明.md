# Finals.id 伙伴应用 · 汉化补丁 使用说明

一句话：双击 `finals-companion.zh.exe` 就是中文版。

汉化文件位置：`E:\Finals.id Companion App\finals-companion.zh.exe`

---

## 一、怎么装

| 想做什么 | 双击哪个文件 |
| --- | --- |
| 直接玩中文版（推荐） | `E:\Finals.id Companion App\finals-companion.zh.exe` |
| 让快捷方式/原程序也变中文 | `2-替换原程序为汉化版.bat`（会自动把原版备份成 `finals-companion.exe.bak`） |
| 玩回原版 | `3-还原原程序.bat` |

中文版和原版共用同一个 Steam 登录，不用重新登录。

---

## 二、怎么改翻译

1. 用 Excel 打开 **`translations.csv`**，只改「中文翻译」这一列（别改其它列）。
2. 保存（编码保持 UTF-8）。
3. **先关掉正在运行的 `finals-companion.zh.exe`。**
4. 双击 **`4-改完翻译后重新打包.bat`**，等窗口跑完。
5. 重新打开 `finals-companion.zh.exe` 就是新译文。

只想浏览、搜索译文：用浏览器打开 `translations.html`。

---

## 三、官方更新后怎么办

1. 官方更新会把 `finals-companion.exe` 换成新版，汉化版**不会自动更新**（还是旧版）。
2. 先把官方应用关掉，然后双击 **`1-生成汉化版.bat`**：
   它会用新版重新生成 `finals-companion.zh.exe`，词库自动沿用。
3. 如果新版界面冒出新的英文，说明词库还没收录——把新版 exe 发给本鱼，我来补词条。

---

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `translations.csv` | **给你改的译文表** |
| `translations.html` | 浏览器里翻/搜译文 |
| `translations.json` | 词库（工具读取，别手改） |
| `1-生成汉化版.bat` | 用官方版生成汉化版 |
| `2-替换原程序为汉化版.bat` | 备份并替换原程序 |
| `3-还原原程序.bat` | 从备份还原 |
| `4-改完翻译后重新打包.bat` | 改完 CSV 后重新生成 |
| `tools\` | 打包工具，不用动 |

---

## 出问题看这里

- **提示「PermissionError」/ 文件被占用**：`finals-companion.zh.exe` 还开着，关掉再打包。
- **提示找不到 python**：需要装 Python 3，并勾选“Add python.exe to PATH”。
- **改的词没生效**：三点检查——CSV 保存了没、程序关了没、4 号 bat 跑完了没。
- **打开后是英文**：确认打开的是 `finals-companion.zh.exe`，不是原来的 `finals-companion.exe`。
