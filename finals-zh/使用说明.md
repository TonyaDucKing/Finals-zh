# Finals.id 伙伴应用 · 汉化补丁 使用说明

一句话：双击 `finals-companion.zh.exe` 就是中文版（和原程序在同一个文件夹里）。

---

## 用之前需要什么

- Windows 10 / 11（64 位）。官方程序本身要 WebView2，一般系统都有。
- **Python 3**（从 python.org 安装，安装时勾选 “Add python.exe to PATH”）。
- 首次双击 bat 会自动执行 `pip install brotli`（需要联网）；也可以手动 `python -m pip install brotli`。
- 程序装在 `Program Files` 这类受保护目录时，「替换原程序」需要管理员权限；只生成 `.zh.exe` 不需要。

补丁只改你本机的一份 exe 副本，不联网、不上传任何数据。

---

## 一、怎么装

| 想做什么 | 怎么做 |
| --- | --- |
| 直接玩中文版（推荐） | 双击程序目录里的 `finals-companion.zh.exe` |
| 让快捷方式/原程序也变中文 | 双击 `2-替换原程序为汉化版.bat`（原版自动备份为 `finals-companion.exe.bak`） |
| 玩回原版 | 双击 `3-还原原程序.bat` |

**程序装在哪个盘都行**，bat 会自动找 `finals-companion.exe`：
先查注册表 → 桌面/开始菜单快捷方式 → 常见目录 → 全盘浅层搜索。
第一次找到后会记到 `安装路径.txt` 里，以后直接用它。

如果它还是找不到（比如绿色版、目录名改过），有两个办法：
1. 把 `finals-companion.exe` **直接拖到 bat 文件上**再松手；
2. 或者双击 bat，在窗口提示时把 exe 拖进黑窗口、按回车。

中文版和原版共用同一个 Steam 登录，不用重新登录。

---

## 二、怎么改翻译

1. 用 Excel 打开 **`translations.csv`**，只改「中文翻译」这一列（别改其它列）。
2. 保存（编码保持 UTF-8）。
3. **先关掉正在运行的 `finals-companion.zh.exe`。**
4. 双击 **`4-改完翻译后重新打包.bat`**，等窗口跑完。
5. 重新打开 `finals-companion.zh.exe` 就是新译文。

只想浏览、搜索译文：用浏览器打开 `translations.html`。

---

## 三、官方更新后怎么办

1. 官方更新会把 `finals-companion.exe` 换成新版，汉化版**不会自动更新**（还是旧版）。
2. 先把官方应用关掉，然后双击 **`1-生成汉化版.bat`**：
   它会自动定位新版 exe，重新生成 `finals-companion.zh.exe`，词库自动沿用。
3. 如果新版界面冒出新的英文，说明词库还没收录——把新版 exe 发给我，我来补词条。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `translations.csv` | **给你改的译文表** |
| `translations.html` | 浏览器里翻/搜译文 |
| `translations.json` | 词库（工具读取，别手改） |
| `1-生成汉化版.bat` | 找到原程序并生成汉化版 |
| `2-替换原程序为汉化版.bat` | 备份并替换原程序 |
| `3-还原原程序.bat` | 从备份还原 |
| `4-改完翻译后重新打包.bat` | 改完 CSV 后重新生成 |
| `安装路径.txt` | 自动记录找到的程序路径，可删（删了会重新找） |
| `tools\` | 打包工具，不用动 |

---

## 出问题看这里

- **提示「PermissionError」/ 文件被占用**：`finals-companion.zh.exe` 还开着，关掉再打包。
- **提示找不到 python**：需要装 Python 3，并勾选“Add python.exe to PATH”。
- **找不到程序 / 定位错了**：删掉 `安装路径.txt` 再试；或把 `finals-companion.exe` 拖到 bat 上。
- **改的词没生效**：三点检查——CSV 保存了没、程序关了没、4 号 bat 跑完了没。
- **打开后是英文**：确认打开的是 `finals-companion.zh.exe`，不是原来的 `finals-companion.exe`。
