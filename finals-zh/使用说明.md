# Finals.id 伙伴应用 · 汉化补丁（免安装 Python）

一句话：双击 **`汉化工具.exe`**，按菜单选 **1** 就能生成中文版。

不需要装 Python、不需要命令行，全部操作都在这个 exe 里。

---

## 一、怎么装

1. 双击 **`汉化工具.exe`**
2. 输入 **1** 回车（它会自己找到你的 `finals-companion.exe`）
3. 生成成功后，程序目录里会多出 **`finals-companion.zh.exe`**，双击它就是中文版

| 菜单 | 作用 |
| --- | --- |
| 1 | 生成汉化版（推荐，保留原程序） |
| 2 | 用汉化版替换原程序（自动备份为 `.bak`） |
| 3 | 从备份还原原程序 |
| 4 | 应用 `translations.csv` 的修改并重新打包 |

如果它找不到程序（绿色版/目录改过名）：**把 `finals-companion.exe` 直接拖到 `汉化工具.exe` 上松手**，会自动生成汉化版。

---

## 二、怎么改翻译

1. 用 Excel 打开 **`translations.csv`**，只改「中文翻译」那一列。
2. 保存（编码保持 UTF-8）。
3. 关掉正在运行的 `finals-companion.zh.exe`。
4. 双击 `汉化工具.exe`，选 **4**。
5. 重新打开 `finals-companion.zh.exe` 就是新译文。

想浏览/搜索译文：浏览器打开 `translations.html`。

---

## 三、官方更新后怎么办

1. 官方更新会把 `finals-companion.exe` 换成新版，汉化版不会自动跟上。
2. 关掉官方应用，双击 `汉化工具.exe` 选 **1**，它会用新版重新生成，词库自动沿用。
3. 新版界面如果冒出新的英文，说明词库还没收录——把新版 exe 发给我补词。

---

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `汉化工具.exe` | 主程序，双击出菜单（**必须和 translations.json 放同一文件夹**） |
| `translations.csv` | 给你改的译文表 |
| `translations.html` | 浏览器里翻/搜译文 |
| `translations.json` | 词库（工具读取，别手改） |
| `安装路径.txt` | 自动记录找到的程序路径，可删（删了会重新找） |
| `tools\` | 源码，普通用户用不到 |

---

## 出问题看这里

- **写入失败 / 权限被拒**：先关掉 `finals-companion.zh.exe`；不行就右键 `汉化工具.exe` →「以管理员身份运行」；还不行多半是安全软件拦截，把 `finals-zh` 文件夹加入白名单。
- **找不到程序 / 定位错了**：删掉 `安装路径.txt` 再试；或把 `finals-companion.exe` 拖到 `汉化工具.exe` 上。
- **改的词没生效**：检查三件事——CSV 保存了没、程序关了没、菜单 4 跑完没。
- **打开后是英文**：确认打开的是 `finals-companion.zh.exe`，不是原来的 `finals-companion.exe`。
